Step-by-Step Checklist

Start With Simple, Observable Checks

When a printer stops working, check the message and basic conditions first. Try one change at a time so you can tell which step made a difference.

  1. Read the exact message

    Write down the complete text or error code and note whether it appears on the printer screen, computer or app.

  2. Check power, paper and covers

    Confirm the printer is powered on, paper is loaded correctly, access panels are closed and no visible jam is blocking operation.

  3. Check connection and selected device

    Review USB or network connectivity, then confirm the computer is sending the job to the intended printer.

  4. Review the print queue

    Look for paused jobs, stuck documents or an offline setting. Follow operating-system instructions to clear or resume jobs.

  5. For quality issues, run a recommended test

    Check paper type and print settings, ink/toner levels, and the printer’s built-in quality or alignment test if available.

  6. Use approved maintenance steps

    Consult the official user guide before cleaning, removing parts or updating firmware. If a physical issue persists, seek qualified assistance.

Scanning Help

Printer Scanning Basics

If printing works but scanning does not, confirm that your Printer Services scanning, that the scan software or app is installed from the official source, and that the computer or mobile device is connected to the printer. Review the manufacturer instructions for selecting a save location and file type.

Important

Follow the instructions for your exact model. Do not force parts, bypass safety features, or install software from unfamiliar sources. If the issue persists, consult the official user guide or request professional assistance.

Before You Start

  • Computer or phone type
  • USB, Wi-Fi or Ethernet
  • Any error message
  • Steps already tried
